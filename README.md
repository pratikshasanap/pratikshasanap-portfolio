# Pratiksha Sanap | Senior Fullstack AI Engineer Portfolio

A modern, high-performance portfolio website built with React 19, Tailwind CSS v4, GSAP, and Vite. Designed following Apple-inspired dark/light aesthetics, high-contrast typography, interactive canvas topology visualizers, and Server-Sent Events (SSE) token streaming architectures.

## Live Highlights

* **Designation:** Senior Fullstack AI Engineer
* **Core Stack:** Python, JavaScript, FastAPI, React, Data Science, Generative AI
* **Cloud Certification:** AWS Certified Cloud Practitioner
* **Design Aesthetic:** Apple space-black & titanium glassmorphism with light/dark theme persistence and hand-drawn vector annotations (`rough-notation`).

## Key Sections

1. **Header Navigation:** Sticky translucent navigation with theme switcher, brand moniker, and quick anchors.
2. **Hero Overview:** Dynamic spotlight headline, designation badging, and MacBook Pro laptop device frame hosting an interactive terminal skills matrix.
3. **Architectural Competencies:** Deep-dive breakdown of 5 core engineering pillars with production deliverables.
4. **AWS Certifications:** Detailed credential breakdown across 5 architectural domains (Security, Compute, High-Durability S3 Storage, FinOps, and Bedrock/SageMaker GenAI).
5. **Technical Deep-Dives (Articles):** Markdown-powered architecture articles with frontmatter parsing, search, shareable deep links, and a full-screen reading modal.
6. **Interactive Contact:** Form with validation, celebration confetti animations, and mail client dispatch.
7. **Footer:** Comprehensive sitemap and technical specifications.

## Local Development

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build production bundle
npm run build

# Preview production build
npm run preview
```
